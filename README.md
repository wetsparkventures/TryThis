# TryThis

Store the things you love (movies, books, music, podcasts, YouTube, restaurants, art, clothes,
cars, trips, anything) and get told what to try next, with the reason. Builds Spotify and YouTube
playlists from your taste, turns goals ("every Best Picture winner", "understand relativity") into
plans with quizzes, and pays for itself with labeled affiliate links that never influence the
recommendations.

Status: planned (2026-11-06). The plan is [TRYTHIS.md](TRYTHIS.md). No code yet.
